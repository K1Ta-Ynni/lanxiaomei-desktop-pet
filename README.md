# 蓝小妹桌宠

给蓝世_1967粉丝玩的桌面小伙伴，使用 Electron 和 JavaScript 从零实现。主体版默认只运行本地桌宠功能；可按需开启 AI，接入 OpenAI 兼容模型进行纯文字聊天，并按明确指令调用本地歌曲、录音和表情包。

立绘原型来源于 **B站 UP 蓝世_1967**，由项目维护者提供并确认可使用。本项目为粉丝作品。代码使用 MIT 许可证；立绘与录音的许可单独说明，见 [素材来源](ASSETS.md)。

## 启动

普通使用者：前往 [Releases](https://github.com/K1Ta-Ynni/lanxiaomei-desktop-pet/releases) 下载 Windows x64 ZIP，完整解压后双击 `LanXiaomei.exe` 或 `START.cmd`，不需要安装 Node.js。当前发布版本为 v2.1.2，尚未签名。第一次使用可先看[游玩指南](PLAY_GUIDE.md)。

开发者从源码启动：

安装 Node.js 22 或更新版本，Windows 双击 `start.cmd`。首次启动安装开发依赖，完成后显示桌宠。也可以：

```powershell
npm.cmd ci
npm.cmd start
```

Electron 下载超时时可使用镜像：

```powershell
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npm.cmd ci
```

已有依赖但 Electron 未下载完成时运行 `npm.cmd rebuild electron --foreground-scripts`。

## 现在可以玩什么

- 启动时显示一次问候；点击蓝小妹时从互动播放列表播放录音，并立即中断上一条语音。语音字幕跟随录音时长，气泡叉号可立即停播并收起。
- 右键或点击齿轮：打开「蓝神のLivehouse」面板。
- 打招呼、蹦一下、摇一摇、休息/唤醒。
- 随机眨眼（间隔约 3～7 秒），休息时保持闭眼；隐藏和系统减少动态效果设置会暂停自动眨眼。
- 点击问候时短暂显示害羞表情，蹦跳时短暂显示闭眼笑表情；底部快捷按钮活动后出现，闲置约 2.6 秒自动收起。
- 大小、音量、静音、点按语音和偶尔待机小动作开关；待机时随机摇摆或蹦跳，不自动发声。点击「保存互动设置」立即生效。

随附的分组录音通过响度测量计算播放增益，尽量统一听感音量，原音频保持不变。

语音和表情包各有独立的互动播放列表。在「蓝神のLivehouse」面板勾选素材，选择随机、顺序循环或单项循环；修改立即保存，重启后保留。默认选中全部表情包和非歌曲语音，歌曲可自行勾选。语音和歌曲导入后会自动分析听感音量，原文件不改写；可在偏好中关闭均衡。顺序按面板编号循环，单项循环重复第一项，每次互动只播放一项。列表为空时跳过该类素材；直接点击录音或缩略图仍可单独点播。静音和音量为 0 只关闭声音，保留字幕与动作。

面板采用侧栏分页。语音、表情包的素材库与「已选列表」并排展示，可折叠全部素材或语音分组；在已选列表点播放/预览、点叉移除。

「音乐播放器」独立管理歌曲播放：暂停/继续、拖动进度、上一首/下一首及顺序/随机/单曲循环，歌曲结束后自动接续。播放歌曲时进入歌姬模式：点按桌宠不会发语音，只按互动设置至多展示一张表情包，不会中断歌曲。鼠标移到桌宠时显示歌曲控件；按缩放大小自适应显示歌曲名/暂停、进度与切歌、播放模式。关闭面板继续听，手动点播语音、隐藏或休息会停止歌曲。可添加 MP3/WAV/OGG/M4A 歌曲（每首最多 500 MiB），导入为歌曲，默认不参与点按语音。普通语音仍限制为每条 30 MiB。语音与歌曲共用音量。

桌宠右键菜单可从 60%、80%、100%、120%、140%、160% 快速切换大小，并标记当前挡位；互动面板滑块继续支持细调。

点按语音和表情包同时开启时，点击会在两者间二选一（约 1/4 概率发图）；表情包不会叠加播放语音。图只显示在头顶的小气泡里，不显示编号；编号仍保留在选图预览，鼠标移入气泡可见关闭叉号。
- 手动点播本地语音、停止播放；新语音会替换正在播放的语音，不叠加。
- 导入本地表情包，点击缩略图让蓝小妹在桌面展示；GIF 保持动画。
- 托盘点击恢复桌宠，双击打开互动面板；桌宠窗口关闭时收进托盘。桌宠、设置与聊天窗口均不占任务栏，退出请使用托盘的“退出桌宠”。
- 游戏模式：`Ctrl+Alt+G` 切换。仅鼠标穿透，不能直接点按或拖动；动画、语音、音乐、表情及陪伴功能照常运行，可通过面板或托盘操作。
- 隐藏/显示：`Ctrl+Alt+H` 独立切换，不改变游戏模式；隐藏时停止当前语音并暂停互动。也可从托盘或互动面板操作。
- 可直接拖动到其他显示器，松手后窗口收进目标屏幕工作区；不同系统缩放下保持设定的逻辑大小，避免反复移动造成窗口膨胀。托盘「回到主屏幕」可恢复主屏位置。
- “蓝神のLivehouse”的“AI 与模型”可开启或关闭 AI。默认关闭且不发送模型请求；开启后提供纯文字聊天、可检查/删除的本地记忆与有限的本地素材工具。
- AI 不合成语音回复。只有用户明确要求播放歌曲/录音、发送表情包或控制歌曲时，模型才会获得对应工具；普通聊天中提到素材不会触发操作。
- AI 与模型页提供 DeepSeek API 接入教程。可选 AI 使用 DeepSeek 开放平台创建的标准 API Key；Harness/DSH 的 App-managed 登录凭据由 Harness 自行管理，不能当作普通 Key 粘贴。
- 语音输入是可选项：界面检测本机已安装的 Windows 语音识别语言，支持“说一句”、唤醒词模式和连续听写。后两种模式关闭聊天窗口后仍会运行；自动发送时直接在后台对话，关闭自动发送则填入聊天框确认。立绘显示监听标记，点击可停止，托盘菜单也能停止/恢复。隐藏、关闭 AI 或退出会停止监听；游戏模式保留已开启的监听，重启默认不开麦。不同系统不一定有相同识别组件，没有组件仍可文字聊天。原始音频不保存、不上传；自动发送的识别文字会发给配置的模型服务。
- 普通回复在立绘上显示第一句（最长 60 字，约 10 秒），双击文字查看完整聊天。录音/表情包操作保留原有字幕和图片展示。明确的“关闭”“暂停歌曲”“下一首”等短指令直接控制本地播放器，不依赖模型是否调用工具。
- 在互动面板手动检查 GitHub 更新；Windows x64 免安装版下载并校验后可原位替换、重启。

当前使用对齐的睁眼、闭眼透明 PNG 切换表情，小动作由 CSS 对整张图实现，不是 Live2D、骨骼动画或独立肢体动作。休息时暂停点按语音与小动作，唤醒后恢复。待机动作不会自动播放录音。

游戏模式与隐藏均为临时状态，重启后恢复普通显示。游戏模式仅改变鼠标穿透状态，保留原先的休息、动画和媒体播放状态。快捷键注册冲突时会在面板提示，仍可通过托盘切换；管理员权限运行的游戏可能拦截快捷键。

## 添加本地语音

v3.0.0 Windows ZIP 的语音、歌曲和表情包库从空白开始。已有媒体、分类与播放列表在原位更新时保留。`start.cmd` 源码运行使用仓库中的素材目录。

打开互动面板的「语音收藏」，点击“添加语音”即可多选 MP3、WAV、OGG、M4A。导入会自动分析音量，也可以点击“均衡现有语音”补处理旧文件。

语音仅在本机播放，不使用 TTS、不上传文件。清单每条需要唯一 ID 和目录内的音频路径，单条最大 30 MiB，最多 200 条。缺失或无效文件会跳过并提示。

## 角色与运行数据

从互动面板添加 PNG、JPG、GIF、WebP，单张最大 10 MiB，最多载入 200 张。点桌宠底部笑脸按钮可预览并发送，点击角色也可随机发送。气泡中图片最长边约 106 像素，6.5 秒收起，GIF 保留动画。图片只在桌面展示。

角色表情可在“蓝神のLivehouse”的互动小屋手动展示，或加入“常驻表情列表”。支持随机轮换、顺序循环、单张常驻、全选/清空及恢复默认，约每 30～60 秒切换；默认选择原始表情、闭眼、闭眼笑、脸红微笑、害羞、困倦、嘟嘴、张嘴、大笑、委屈和无语，惊讶和疑惑可手动加入。列表清空后显示原始表情。点按问候会害羞，短时间连续点按会嘟嘴或无语，蹦跳时闭眼笑；普通语音播放时有简单张嘴动画，歌曲使用独立音乐动画。临时互动结束后恢复常驻表情；休息时闭眼，隐藏时暂停互动。

`character/character.json` 保存名字、简介、图片路径、展示尺寸和点按问候，不需要配置人设或提示词。当前立绘展示框为 244 × 360 像素，可使用面板缩放。

互动设置保存在：

```text
%APPDATA%/lanxiaomei-desktop-pet/preferences.json
```

Windows 免安装版的用户语音包和表情包保存在 `%APPDATA%/lanxiaomei-desktop-pet/media/`。首次升级会从旧版应用目录复制已有媒体；已有同名用户文件优先保留。下载的更新包和旧程序备份暂存在同一用户数据目录下的 `updates/`。

新增的随附语音会补齐缺失录音并合并新 ID 到用户清单，保留原有自定义条目和标签。首次合并前备份清单为 `manifest.before-bundled-import.json`。

AI 关闭时不发起模型请求。开启后的聊天内容、近期上下文和长期记忆会发送给用户配置的模型服务商，可能按服务商政策留存或计费。API 密钥通过 Electron safeStorage 使用系统加密存储。聊天记录、长期记忆分别位于用户数据目录下的 `conversation.json` 和 `assistant-memory.json`；可以在聊天窗口分别清理。只有明确说“记住……”或在记忆面板手动添加的内容会成为长期记忆。

v2.1 起只提供一个主体版，DSH 计划以后以独立插件扩展，目前尚未接入。新安装默认关闭 AI；旧 v2 升级保留原有 AI 开关，不会删掉模型配置、聊天记录、记忆或自定义媒体。开发测试使用独立临时目录，不修改日常设置。

## 开发

所有互动均提供统一的本地调用入口，供当前界面和后续 AI 工具使用：

```js
const catalog = await window.petApp.interactions();
await window.petApp.executeInteraction({ type: 'jump' });
await window.petApp.executeInteraction({ type: 'showSticker', id: '开心.gif' });
```

完整接口与参数见 [INTERACTIONS.md](INTERACTIONS.md)。可选 AI 只将其中的本地媒体操作作为模型工具；这组入口没有监听外部网络端口。

```powershell
npm.cmd test
npm.cmd run test:desktop
npm.cmd run test:settings
npm.cmd run test:music
```

桌面测试启动真实 Electron，检查动作、睡眠、设置持久化、语音播放和AI 开关切换。`npm.cmd run test:companion` 使用本地测试服务验证对话、工具调用、密钥加密、记忆与降级中止，不访问真实模型或开启麦克风。`test:settings` 会用真实鼠标测试悬停按钮、点击齿轮、恢复已最小化/隐藏的设置窗口和连续点击；运行时请暂时不要操作鼠标。Windows 打包冒烟测试解压 ZIP 再启动，更新助手演练检查原位替换与媒体迁移。测试使用临时生成的素材和数据，不需要角色录音或模型密钥；截图放在被 Git 忽略的 `artifacts/`。

`npm.cmd run test:dpi` 会移动真实鼠标，在当前连接的各显示器上检查连续拖动和跨屏尺寸；运行时请暂时不要操作鼠标。测试使用独立数据目录，不修改系统缩放。

更新器仅在点击「检查更新」后请求 GitHub Releases。下载前核对来源和平台、下载后核对附件 SHA-256；Windows 打包版可自动替换程序，源码运行不支持自替换。发布流程和媒体保留行为见 [更新说明](UPDATING.md)。

```text
assets/portraits/        透明立绘与头像
assets/voices/           本地录音与播放清单
assets/stickers/         本地表情包
character/              角色基本配置
src/main.js             窗口、托盘、IPC、本机存储
src/companion.js        动作定义、设置校验、语音清单读取
src/preload.cjs         页面可调用的具体功能
src/pet.*               透明桌宠与音频播放
src/settings.*          互动面板、AI 开关与模型配置
src/chat.*              文字聊天、可选语音输入与记忆界面
test/                   单元测试
scripts/smoke.mjs       真实桌面功能测试
.github/workflows/      自动检查
```

在 Windows x64 上运行 `npm.cmd run package:windows` 生成主体版免安装 ZIP（位于被 Git 忽略的 `dist/`），再运行 `npm.cmd run test:package` 检查。另附带 `-companion` 文件名的旧 v2 更新兼容包，仅内部迁移标记不同，功能相同，并非另一种发行版。`npm.cmd run test:upgrade-v2` 使用 v2 原始更新器验证两种旧包升级。打包只复制应用代码、素材、文档和 Electron 运行时，不包含开发依赖、测试缓存或本机设置。

后续可增加动作素材、更多脚本互动，再考虑 AI。开发约定见 [CONTRIBUTING.md](CONTRIBUTING.md)，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

# 蓝小妹本地语音包

这里放蓝小妹的录音文件，支持 MP3、WAV、OGG，单条不超过 30 MiB。当前清单为空，项目没有附带角色录音。

将可使用的音频放入本目录后，编辑 `manifest.json`：

```json
{
  "clips": [
    { "id": "hello", "label": "打招呼", "file": "hello.mp3", "text": "录音对应的可选字幕" }
  ]
}
```

`id` 用英文字母、数字、下划线或短横线，且每条不同；`file` 是本目录内的文件相对路径。保存后到互动面板点击“刷新语音包”，可手动点播或开启点击时随机播放。录音是本地播放，不会上传、合成或发到聊天软件。

清单里不要登记尚不存在的文件。对外分发的音频请同步在项目 `ASSETS.md` 标注来源和许可。

# 蓝小妹本地语音包

这里放蓝小妹的录音文件，支持 MP3、WAV、OGG，普通语音每条不超过 30 MiB；歌曲每首可到 500 MiB。当前清单包含维护者提供的 31 段录音，文件位于 `lanjie/`。

将可使用的音频放入本目录后，编辑 `manifest.json`：

```json
{
  "clips": [
    { "id": "hello", "label": "打招呼", "file": "hello.mp3", "text": "录音对应的可选字幕" }
  ]
}
```

`id` 用英文字母、数字、下划线或短横线，且每条不同；`file` 是本目录内的文件相对路径。保存后到互动面板点击“刷新语音包”，可手动点播或勾选加入互动播放列表，支持随机播放、顺序循环和单曲循环。录音是本地播放，不会上传、合成或发到聊天软件。

可选字段 `group` 指定分组，`duration` 为秒数，`random: false` 表示默认不加入互动播放列表；歌曲分组也默认不选。当前 7 段歌曲可手动点播，也可自行勾选后参与列表播放。

在「音乐播放器」页面可连续听歌、暂停/继续、拖动进度和切歌，独立歌单支持顺序、随机与单曲循环。`music: true` 或唱歌/歌曲/音乐/song/songs/music 分组会被识别为歌曲，默认排除出点按语音。也可直接点「添加歌曲」导入本地音频，无需手写清单；导入文件与原文件分开保存。

随附录音的响度测量保存在 `loudness.json`，目标为 -18 LUFS，真峰值保留 -1.5 dB 余量。播放时按每段的测量结果调整增益，再叠加用户设置的主音量；原始录音不重编码。文件哈希不匹配时不套用旧测量值，避免用户替换音频后使用错误增益。可运行 `python scripts/measure-voice-loudness.py` 重新测量（仅测量时需要 FFmpeg）。

点按角色会立即中断当前语音，再播放下一条。语音字幕随录音显示，可点气泡叉号停止并收起。若同时启用随机表情包，点击时在语音和图片之间二选一，约 1/4 概率选图片；发表情包时会停止当前语音。

清单里不要登记尚不存在的文件。对外分发的音频请同步在项目 `ASSETS.md` 标注来源和许可。运行 `node scripts/import-voices.mjs` 可从 `artifacts/蓝姐语音包/` 导入并生成清单，导入时需 FFmpeg 的 ffprobe，运行桌宠无需 FFmpeg。
